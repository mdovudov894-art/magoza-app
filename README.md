# Шиноси маҳсулот: системаи фурӯш бо баркод (оффлайн)

Кассаи мағозаи хӯрока: баркодро скан мекунед, барнома ном ва нархро нишон медиҳад,
сабад, пардохт ва чекро идора мекунад. Интернет лозим нест.

## Пахш кардан
1. MongoDB-и локалӣ бояд кор карда истода бошад.
2. `npm install`  (як бор)
3. `npm run dev` (барои таҳия) ё `start.bat` (барои мағоза: худаш аз нав пахш мешавад, агар афтад).
4. Браузер: http://localhost:3000
5. Бори аввал саҳифаи «Сохтани соҳиб» мебарояд: ном, логин ва паролро нависед.

## Санҷиши муваққатӣ дар Vercel
Vercel барои санҷиш дастгирӣ мешавад; ин ҷойгиркунӣ барои истифодаи воқеии касса омода нест.

1. Лоиҳаро ба GitHub фиристед. Папкаҳои `node_modules` ва `backups`, инчунин `.env`, аз рӯи `.gitignore` дохил намешаванд.
2. Дар MongoDB Atlas як базаи алоҳидаи санҷишӣ созед; backup-и мағозаи воқеиро ба он бор накунед.
3. Лоиҳаро дар Vercel аз GitHub импорт кунед. Build Command лозим нест; `public` ҳамчун output directory истифода мешавад.
4. Дар Project Settings → Environment Variables тағйирёбандаи `MONGO_URI`-ро бо connection string-и Atlas илова карда, deployment-ро аз нав иҷро кунед.
5. Дар Vercel URL-ро кушоед, аккаунти соҳибро созед ва танҳо маълумоти санҷиширо ворид кунед.

Барои пайваст шудани Vercel ба Atlas, қоидаи шабакаи Atlas бояд дастрасии сервери Vercel-ро иҷозат диҳад. Агар барои санҷиш рӯйхати `0.0.0.0/0` истифода шавад, танҳо бо базаи холӣ ва корбари базаи дорои пароли қавӣ истифода кунед; пас аз санҷиш ин қоидаро нест кунед. Connection string-ро дар код ё GitHub нанависед.

Дар Vercel файлҳои маҳаллӣ ва scheduler-и доимӣ вуҷуд надоранд: Backup дар ин санҷиш ғайрифаъол аст ва backup-ҳо/файлҳои лоиҳаи маҳаллиро ба он бор кардан лозим нест. Маҳдудкунандаи кӯшиши login дар хотираи раванд буда, байни serverless instance-ҳо муштарак нест. Импорти файлҳои калон низ метавонад аз маҳдудияти дархости Vercel гузарад. Барои ҳамин ин ҷойгиркунӣ танҳо санҷиши муваққатист, на ҷойгиркунии истеҳсолӣ.

## Нақшҳо
- **Кассир:** танҳо фурӯш (скан, сабад, пардохт, чоп, ёфтани чек).
- **Менеҷер:** + маҳсулот, анбор, аксияҳо, таърихи фурӯш, бозгашт, ҳисобот, журнал.
- **Соҳиб:** + корбарон, танзимот, backup.

## Чӣ дар дохил аст
Логин ва нақшҳо, сабад + ҳисоби умумӣ, пардохт (нақд/корт) + чеки чопӣ, баркоди тарозу (маҳсулоти вазнӣ),
backup-и худкор + барқарорсозӣ, чанд касса дар як шабака, анбор бо ҷузъҳо ва санаи истифода (FEFO),
воридоти оммавӣ аз Excel/CSV, аксияҳо ва тахфифҳо, ҳисоботҳо + Excel, бозгашти пурра/қисман,
журнали тағйирот (таърихи нарх), забонҳои тоҷикӣ ва русӣ.

## Чанд касса дар як мағоза
1. Як компютер сервер мешавад: дар он `start.bat` кор мекунад (ва MongoDB).
   `install-autostart.bat` онро ҳангоми ворид шудан ба Windows худкор пахш мекунад.
2. `open-firewall.bat`-ро як бор бо «Run as administrator» пахш кунед.
3. Ҳангоми пахш шудани сервер дар равзана адресҳо менависад, масалан `http://192.168.1.10:3000`.
   Дар кассаҳои дигар ҳамин адресро дар браузер кушоед.
4. **Сканерҳои USB** (ба монанди клавиатура рақам менависанд) бе камера кор мекунанд. Камераи браузер танҳо
   дар `localhost` ё `https` кор мекунад, пас барои кассаҳои шабакавӣ сканери USB тавсия мешавад.

## Баркоди тарозу
Дар «Танзимот» формати баркоди тарозуи худро нависед (пешфарз: `2 IIIII c WWWWW c`). Барои маҳсулоти вазнӣ
дар «Маҳсулот» майдони PLU-ро пур кунед ва воҳидро «кг» гузоред.

## Анбор ва муҳлат
Маҳсулот дар «Анбор» бо «Қабули мол» ворид мешавад (миқдор, муҳлат). Аз ин лаҳза захира ҳисоб мешавад,
маҳсулоти муҳлаташ гузашта намефурӯшад ва аввал аз ҷузъи муҳлаташ наздиктар кам мешавад.
Маҳсулоте, ки ҳеҷ гоҳ дар анбор қабул нашудааст, бе ҳисоби захира мефурӯшад.

## Backup
Ҳар рӯз худкор дар папкаи `backups` (ё `BACKUP_DIR`) нусха сохта мешавад (охирин 40 нигоҳ дошта мешавад).
Нусхаҳоро ба флешка ё диски дигар ҳам нусхабардорӣ кунед. Барқарорсозӣ: Танзимот, Backup.

## Муҳити зист
- `MONGO_URI` (пешфарз `mongodb://127.0.0.1:27017/product-scanner-barcode`), `PORT` (3000), `BACKUP_DIR`.

## Муҳим пеш аз фурӯш ба мағоза
- Талаботи қонунӣ ва андозии чек (ККМ, ҲҲС) бо муҳосиб ва мақомоти андоз санҷида шавад.
- Бо дастгоҳҳои воқеӣ (сканер, принтер, тарозу) санҷед ва якчанд рӯз дар паралл бо системаи кӯҳна кор кунед.
